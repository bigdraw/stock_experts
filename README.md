## 为什么需要小雷？

你有东方财富、同花顺、雪球——每个都能看行情。但当你想问"茅台值不值得买"时，得到的只是冰冷的 PE 数字。**你**变成了人肉分析师：在软件之间切换、手动算 ROE、把大把时间花在"帮自己分析"上。

> *"我不想自己算 PE 了。"*
> *"那让小雷替你算。"*

小雷是一只活泼的 AI 股神⚡。他住在你和 9 位投资大师之间——你问一只票，小雷替你取数据、找大师辩论、给总结。你只需要做一件事：**看结论，做决策。**

## 小雷能做什么

| 能力 | 说明 |
|------|------|
| ⚡ **自动取数** | 提问含股票代码 → 小雷自动采集平台数据（K 线/财报/行业/宏观/市场状态）注入大师上下文，大师引用真实数据下结论 |
| ⚖️ **多大师辩论** | 选 ≥2 位大师辩一只票：小雷先整理客观事实（FactBook），再大师分析 → 质疑 → 回应 → 中立总结，全程思维链可见 |
| 🧠 **思维链可折叠** | 大师思考过程实时流式展示，灰色可折叠面板，工具调用中断后自动恢复 |

| ⏹️ **硬停 + 并行辩论** | 点"停止"真停（发信号给后端，不偷偷后台续跑）；支持同时开多个辩论并行流式 |

| 📈 **历史 K 线** | 2010 年至今全量数据，日/周/月/季/年K本地秒切，多数据源容错 + 坏数据自动过滤 |

## 快速开始

### 一键启动

```bash
# Windows
scripts\start.bat

# Linux / macOS
bash scripts/start.sh
```

### 手动启动

```bash
# 后端
cd backend && uv sync
cat > .env <<'EOF'
LLM_API_KEY=your-llm-key
TAVILY_API_KEY=your-tavily-key   # 辩论 FactBook 行业/宏观采集；无 key 自动降级 DuckDuckGo
EOF
uv run uvicorn app.main:app --reload --port 8000

# 前端
cd frontend && npm install && npm run dev    # http://localhost:5173
```

打开前端，在对话里输入 `分析 600519` 或点 `⚖️ 辩论` 让大师辩一只票，开始你的投资之旅。

## 理念

> *大师给判断，数据给事实，小雷让它们相遇。*

| 原理 | 一句话 |
|------|-------|
| 数据驱动优先 | 所有判断基于量化数据，不靠"感觉" |
| 大师理念 + 工具数据 | 理念决定框架，数据决定结论 |
| 不瞎编 | 股票不存在就说不存在，不幻觉 |
| 单一真相源 | LLM 配置 DB 存、回测纯 pandas、行情多源容错 |
| 可验证才算完成 | 测试通过、ruff clean、build 过 |

## 技术栈

- **后端**：Python 3.12+ / FastAPI / SQLAlchemy[asyncio] + aiosqlite / APScheduler / RestrictedPython（沙箱）/ akshare（A 股数据）
- **前端**：Vue 3.5 + TypeScript / Naive UI / ECharts / Pinia / Vue Router / markdown-it + highlight.js / DOMPurify
- **LLM**：OpenAI 兼容接口（统一 base_url + api_key 配置，DB 真相源，流式 + 思考链 + function-calling）
- **设计**：暖奶油 + 珊瑚 + 蜜糖 + 鼠尾草绿（A 股红涨绿跌文化正确），圆角⚡签名元素，Nunito 圆角字体
